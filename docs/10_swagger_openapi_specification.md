# REST API Swagger/OpenAPI Endpoints Specification

Danh sách Endpoints chính theo OpenAPI Specification:
- **Identity**: `/api/auth/login`, `/api/auth/register`, `/api/wallets/balance`, `/api/wallets/topup`, `/api/wallets/pay`
- **Catalog**: `/api/categories`, `/api/products`, `/api/flashsales`
- **Inventory**: `/api/stocks`, `/api/stocks/reserve`
- **Ordering**: `/api/cart`, `/api/orders`, `/api/orders/checkout`
- **Notification**: `/api/notifications`
